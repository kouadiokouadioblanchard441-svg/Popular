---
name: TGOOD web presentation
description: The approved presentation mode for the TGOOD site.
---

Keep TGOOD presented as a conventional website rather than an app-like mobile shell or standalone PWA.

**Why:** The user explicitly asked to return the site to its previous presentation after the mobile app effect was introduced.

**How to apply:** Preserve the original page spacing and navigation behavior. Do not add fixed app-shell spacing, standalone display metadata, service-worker behavior, or mobile-only interaction styling unless the user explicitly requests it.
